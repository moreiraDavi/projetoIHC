# Lopu — Site de compra e venda de carros clássicos 🚗

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white&style=for-the-badge)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white&style=for-the-badge)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black&style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Finalizado-green?style=for-the-badge)

Protótipo navegável de um site de compra, venda e anúncios de **carros antigos**, desenvolvido para a disciplina de **Interação Humano-Computador (IHC)** no curso de Ciência da Computação do CEUB. O foco do projeto foi a **experiência do usuário**: navegação clara, formulários simples e páginas de ajuda.

---

## 📄 Páginas

| Página | Descrição |
|---|---|
| [`index.html`](index.html) | Página inicial com carrossel de destaques e vitrine de carros |
| `Bmw.html`, `Mercedes.html`, `Volkswagen.html`, `Mitisubish.html`, `pegeout.html` | Catálogo por marca, com carrossel de fotos, preço, ano e quilometragem |
| [`carro.html`](carro.html) | Ficha técnica do carro (fabricante, ano, motor, desempenho) |
| [`visualizar.html`](visualizar.html) | Mural com as postagens e comentários da comunidade |
| [`anunciar.html`](anunciar.html) | Formulário para anunciar um carro (placa, marca, modelo, ano, quilometragem, preço e foto) |
| [`Login.html`](Login.html) / [`formulario.html`](formulario.html) | Login e cadastro |
| [`ajuda.html`](ajuda.html) | Central de ajuda: sobre a empresa e como participar |

## ⚙️ Tecnologias

- **HTML5** e **CSS3**, com uma folha de estilo por página (pasta [`estilos/`](estilos))
- **JavaScript** puro para o carrossel de imagens

## 🚀 Como abrir

Não precisa instalar nada: basta abrir o `index.html` no navegador.
